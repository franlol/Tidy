# Tidy

A cleaner interface for WoW Forever: action bars, square icons and Blizzard's
bars where you want them.

## Features

- **Action bars**: up to 13 bars built on LibActionButton. Layout, paging
  (stances, forms, modifier keys), visibility conditions, fading, presets, and
  drag with snapping to other bars and the screen.
- **Blizzard's bars**: pet, stance, micro menu, bags, XP / reputation, extra
  button, leave vehicle and queue status, moved and scaled like any bar.
- **Buttons**: cooldown darkness, global cooldown spark, flat cast animation,
  flashes for presses on cooldown / not usable / empty slots, ready flash.
- **Keybinding mode**: hover a button and press a key.
- **Square icons** with a flat border on action bars, auras and item buttons.
- **Profiles** per character, with export / import.
- English and Spanish.

Tidy's bars stay off while another action bar addon is loaded.

## Commands

- `/tidy`: open the options
- `/tidy lang en|es`: language
